## CSS Practical Programs
This project contains the CSS practical experiment pages with line-by-line code and visible demonstrations.

## Output and Assets
- 75 CSS experiment pages are included.
- CSS experiment pages do not contain repeated audio/video players.
- Image-based experiments display actual image output.
- Image assets are also stored in `assets/images/`.
- Experiment 69 demonstrates sliding image/card animation.
- Each CSS experiment contains a visible output area and a code section.

## Important
The CSS pages contain an embedded copy of the shared stylesheet and embedded copies of their demonstration images. This makes individual experiment pages work reliably when opened directly in Chrome from a local folder.
